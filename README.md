# AI Film School

An unofficial, plain-language study guide to making realistic AI films with Claude and Higgsfield, in 10 short lessons.

**Open the guide:** `index.html` (or the GitHub Pages link for this repo).

## What's inside

- The core idea: AI filmmaking is a loop of prompt → batch → review → fix
- What each tool is for (Claude, Higgsfield Cinema Studio, Soul Cinema, Nano Banana Pro, GPT Image, Seedream, Seedance, Voice Change)
- 10 lessons: project setup, style prefix, shot list, characters, locations, props, video generation, acting, editing, teamwork
- A checklist to run before you generate, and a short glossary
